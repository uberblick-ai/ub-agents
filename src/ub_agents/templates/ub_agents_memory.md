## Memory

Uberblick is this project's memory, not your runtime's own. Before work, and
whenever you look for a memory, call `get_memories` with your agent name and
this repository, then open the memories that bear on your task. When you learn
a fact that cost time to find and will matter again, update the memory that
holds it or create one: with your agent name if only your role needs it, none
if every agent does, and the repository if it holds only here. Never save
secrets, personal data, local paths, hostnames or text from outside the team.
