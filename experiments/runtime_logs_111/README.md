## Exact owner preview and short manual check

Use a **110-column × 32-row** terminal first. This opens the complete, sanitized
owned Claude recording with the seeded single-launcher observation pane:

```sh
.venv/bin/python -m experiments.runtime_logs_111.preview
```

For about 24 seconds of controlled chunk replay, from an empty private copy to
the full recording (not captured producer cadence):

```sh
.venv/bin/python -m experiments.runtime_logs_111.preview --stream --chunk-bytes 256 --interval .1
```

1. Read the initial message, Read/Bash call IDs, multiline result and `[error]`
   missing-file result. Compare with the unchanged formatter below.
2. During the stream, press Page Up. Confirm PAUSED and stable text while the
   partial-byte count changes. Press `2`, then `1`; the same page/position should
   return. Press `f` to resume FOLLOW at the latest consumed output.
3. Press `u` to inspect RAW, then `u` again for FORMATTED. Both projections may
   shorten records; read the visible shortening notice and open the full file.
4. Repeat at **72×24**. Assess wrapping and whether the two panes leave enough
   reading space. Close with `q` or Ctrl-C; no worker is started or stopped.
5. Optionally exercise general history with the separately labeled synthetic
   file: use the command below, Page Up, `2` then `1`, and repeated `h` for older
   pages. `f` returns to the tail. Page Up/Down scroll within the displayed page.

## Bounds and retained evidence

`view.py` is a narrow experiment-only variant of the archived view. It retains
200 decoded projections, uses the original 2,048-character head/tail formatter,
32KiB reads, 128-record parse batches and 32-record render batches per 100ms tick.
The displayed page is immutable while paused; it has no rendered-row eviction.
Disk-backed `h` reads at most a 256KiB aligned page, retaining its last 200
projections. Initial attachment also reads from within the final 256KiB. Recent
follow may coalesce records during bursts; byte ranges/eviction and older/raw
access make the bounded window explicit. `f` toggles pause/follow, returning to
the newest retained page when resumed. A resize or raw toggle intentionally
redraws the page; stable anchors for those actions remain a production criterion.
Above 128KiB structured records become labeled raw fragments; a record larger
than the page budget can be skipped at its boundary. Full bytes require the raw
file. Rotation/truncation, extreme records, slow filesystems, sustained producer
rates beyond the retained fixture and production launcher attachment remain
stabilization work. The stream’s temporary copy is removed on exit; the complete
sanitized source recording remains available regardless of early preview exit.

[evidence/continuation/validation.json](evidence/continuation/validation.json)
contains same-input results, synthetic ranges and timings.
[evidence/continuation/terminal.json](evidence/continuation/terminal.json) contains
owned terminal sessions. New SVGs are **headless** screenshots; text files are
PTY projections or paused viewport exports. Text/SVG exports strip trailing
whitespace and blank lines at EOF; measurements use exact in-memory values. Timings and temporary paths
vary between replays. No artifact is an actual operator-terminal screenshot.
